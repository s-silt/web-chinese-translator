# 隐私说明

适用于浏览器扩展「网页汉化助手」。Chrome、Edge 提供固定词库、模型翻译与阅读辅助；Firefox 版本仅启用 GitHub 本地汉化，不运行模型与阅读辅助。扩展在无痕（隐私）窗口中不运行（`incognito: 'not_allowed'`），无痕窗口不会记录或附带页面标题。

## 处理的数据

| 数据       | 内容                                                                                                   | 存放位置                                                                              |
| ---------- | ------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------- |
| 页面文字   | github.com、gist.github.com、www.githubstatus.com 页面上的界面文字，在本地替换为中文                   | 不保存                                                                                |
| 页面文字   | 26 组预置站点（完整域名见 src/translation/dictionaries/metadata.json）上的常见界面文字，用内置词库在本地替换为目标语言 | 不保存                                                                                |
| 翻译文本   | 你选中的文字及附近可见上下文、你手动要求翻译的当前网页或已开启自动翻译的站点的可见文本、当前页标题、主标题与站点名等元数据；开启「智能陪读」后，停留或回读的候选段落也会发送给你自己配置的模型接口 | 划词释义与陪读结果仅在后台内存中短期缓存。普通页面的直接翻译和自动翻译结果还会明文写入本机 IndexedDB（web-translator-cache），不随账号同步；译文可能包含原文片段、标识符或网址。缓存键由原文、语境、接口、模型和提示词等计算 SHA-256 摘要，这些输入不作为独立明文字段保存。最多约 20000 条或 20 MB；写入超过 30 天的条目不再用于命中，物理删除由后续清理触发；可识别敏感页的译文，以及带近期阅读线索的请求，不读写持久层。 |
| 阅读线索   | 仅智能陪读：最近页面的标题（最多 160 字符）、首个可见主标题（最多 120 字符）、站点名和时间戳、标签页 id 与页面 id；不保存完整 URL、浏览历史列表或整页正文。开启智能陪读后，每次模型请求最多附带 4 条来自其他标签页、其他网站的近期线索 | `storage.session`，仅扩展受信上下文访问，最多 12 条、30 分钟过期；关闭智能陪读、总开关、撤销网站权限或修改排除列表时清除；浏览器会话结束后清除 |
| 设置       | 开关、排除路径、翻译语言、界面语言、外观                                                               | `storage.sync`，可能随浏览器账号同步；界面语言与外观另缓存在扩展页面的 `localStorage` |
| 自定义词条 | 你添加的原文与译文                                                                                     | `storage.local`                                                                       |
| 翻译配置   | 模型接口地址、模型名称、自动翻译站点、排除网站（最多 50 个域名）、内置界面词库开关、自定义词典（仅本机存储；启用词典需要对应网站的访问权限，词条只用于本地替换、不发送内容） | `storage.local`                                                                       |
| API Key    | 你填写的模型接口密钥                                                                                   | 本机 IndexedDB（`web-translator-secrets`），不随浏览器账号同步，明文保存；与接口来源（协议、主机、端口）绑定，更换来源需重新填写或显式删除 |
| 自定义请求头 | 你在高级设置中填写的请求头，可能包含服务凭据 | 与 API Key 相同，保存在本机 IndexedDB（web-translator-secrets），明文保存、不同步；与接口来源绑定，只发送给对应模型接口 |
| 页面标记   | 翻译期间 `<html>` 上的 `data-gcn-i-<随机 id>` 属性，页面脚本可读取                                     | 不保存，停用时移除                                                                    |

## 保留与删除

- 删除密钥请使用设置页的「删除密钥」。关闭智能陪读或扩展总开关可清除近期阅读线索。普通的历史记录或缓存清理不等于执行这些删除操作；卸载及浏览器清理选项对扩展数据的处理范围由浏览器管理，本项目未覆盖验证所有浏览器版本与磁盘压力情形。
- 清除持久译文缓存请使用设置页的「清除翻译缓存」，它会清空本机 IndexedDB 中的全部译文和后台内存中的翻译结果，并取消进行中的翻译请求；清除失败会提示。除此之外，删除密钥、关闭总开关、修改排除网站或更换接口都不会删除已有条目。更换接口或模型后使用不同缓存键；换回相同配置且条目未过期时可能再次命中。过期条目不再用于翻译，但不保证立即从磁盘删除，后续写入触发的扫描会按使用时间及容量清理。
- 修改排除网站列表时会清除既有阅读线索；清理失败会提示，且发送前仍会过滤排除网站和可识别高敏主机的旧线索。

## 网络请求

- 已保存的 API Key 会在模型请求、连接测试和获取模型列表时以 `Authorization: Bearer` 发送给你配置的接口；已保存或当前填写的自定义请求头也会随相应请求发送。
- 停用、排除当前页、进入排除路径、改自定义词条、改时间本地化开关时，若当前页是 Turbo 缓存副本、带有 GitHub 缓存写回的译文或残留的旧译文（如扩展更新后），重新请求当前 GitHub 页面；没有 Turbo 时整页重新加载。
- GitHub 从自身缓存写回带译文的标题或页面元素时（前进后退，或帧导航到带锚点的地址），若已停止翻译，或这些译文已过时（如之后改过自定义词条、时间本地化开关，或扩展更新过），重新请求当前 GitHub 页面。
- Chrome、Edge 中扩展更新、卸载或在浏览器中停用时，若当前页是 Turbo 缓存副本或带有 GitHub 缓存写回的译文，重新请求当前 GitHub 页面。
- 以上重新请求被帧导航打断，且旧译文仍在页面上时，再请求一次。
- 点弹出页「刷新」时重新加载当前页。
- 点击「保存并连接」时，向所配置的模型接口发送一条固定测试文本，验证接口与模型是否可用；这条请求不包含网页内容。
- 点击"获取模型"时，向当前填写的接口发送 `GET /models` 请求，使用对应的 API Key 与自定义请求头；不发送网页文字。模型列表仅用于选择，也可手动填写模型名。
- 使用划词辅助时，把所选文字、附近少量可见上下文及当前页的标题、主标题和站点名 POST 到你配置的模型接口（根据所选接口类型使用 OpenAI 兼容的 `/chat/completions` 或 `/responses`）。右键手动翻译发送所选文字和当前页元数据。"翻译本页"会处理当前页的可见可翻译文本，并采用相同的敏感内容与排除规则。
- 在设置页选择智能陪读后，按浏览器提示授予网站访问权限；界面内说明会使用的文字、上下文及短期阅读线索。停留或回读的候选段落会发送给同一接口；每次模型请求最多附带 4 条近期阅读线索。停留、回读次数与操作方式仅用于扩展本地判断，不发送给模型；模型仍会知道请求由划词还是回读触发。常见账户、密钥、付款、邮件等敏感路径与已知敏感主机（含哈希路由与私有网络地址）禁止划词提示、主动陪读、自动翻译与线索记录；仅显式右键菜单可发送所选敏感文字，且不附带页面标题、附近上下文或近期线索。这些识别是启发式的，不保证覆盖全部隐私页面。
- 在「不调用模型的网站」中列出的域名及其子域名上，禁止一切模型发送与阅读线索记录，包括右键手动翻译；固定词库仍可正常工作。
- 在你逐站点开启自动翻译并授予网站访问权限后，相应站点把可见英文文本发送给同一接口；单页发送量有上限，失败片段保留原文，可手动重试，部分错误会暂停本页自动翻译。该接口可能是第三方服务（包括 Gemini 等模型的兼容中继），费用由你与该服务方约定；发送前请确认站点内容可交给该服务处理。
- 固定词库匹配与替换不调用模型；GitHub 恢复翻译时可能重新加载页面，条件见上文。除上述外不发起其他网络请求。

## 权限说明

- `storage`：保存设置、自定义词条与翻译配置；`storage.session` 保存近期阅读线索。
- `scripting`：注册并注入 GitHub 词库脚本与按站点注册的页面脚本。
- 内置必需站点：github.com、gist.github.com、www.githubstatus.com（GitHub 汉化）与 26 组预置站点（固定词库，完整域名见 src/translation/dictionaries/metadata.json）。
- `activeTab`：点右键菜单「翻译本页」、「翻译选中文字」或操作弹出页时，临时访问当前页注入翻译面板脚本。
- `contextMenus`：注册「翻译本页」与「翻译选中文字」右键菜单。
- `optional_host_permissions`：模型接口和自动翻译站点分别按来源授权。开启划词辅助需授予 HTTP/HTTPS 网站访问权限，并注册相应页面脚本；撤权后取消请求、恢复原文、停止相应处理并清除近期阅读线索。
- `alarms`：Chrome、Edge 后台清理过期阅读线索。超过 30 分钟的线索不再参与请求；定时清理可能受浏览器休眠影响。
- 不申请 `tabs`、`history` 权限，也不读取浏览器的浏览历史列表。Firefox 构建仅运行 GitHub 汉化。

## 不做的事

- 固定汉化功能不向开发者或任何第三方发送数据。
- 不内置任何模型服务地址与密钥；不向扩展开发者回传配置、密钥或页面内容。
- 不出售、不转让数据，不用于广告、信用评估或与翻译无关的用途。
